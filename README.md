# Kanishk Dadhich — Portfolio

Personal portfolio site for Kanishk Dadhich, penetration tester and security researcher.

Static, dependency-free multi-page site (HTML/CSS/JS):

- `index.html` — Home
- `work.html` — Work & experience
- `writing.html` — Writing & field notes
- `about.html` — About, capabilities, education
- `contact.html` — Contact (Formspree-backed form)
- `styles.css` — shared design system (dark + light themes)
- `app.js` — theme toggle, mobile menu, scroll reveals, contact form

## Run locally

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Deploy

Served via GitHub Pages from the `main` branch.
