About

Technical curiosity, paired with professional discipline.

Security is most useful when it creates confidence. My work balances an attacker’s mindset with the evidence, context, and communication teams need to fix what matters.

How I work

I work across web application security, API testing, vulnerability assessment, and network enumeration. My hands-on practice combines structured labs, CTF challenges, bug bounty research, and home-lab projects built around real defensive and offensive workflows.

Whether I’m mapping an attack surface or validating a finding, I focus on reproducible evidence and sensible remediation—not noise for its own sake.

Working principles

  • Scope first, test with intent
  • Validate manually before escalating
  • Report impact in business language
  • Practice responsible disclosure
